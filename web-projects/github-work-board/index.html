            Already have a backup?

            If you set this board up in another browser, you do not need a new token. Copy the backup from that board's Settings and paste it into step 4 below. Every token comes back, with its name.

            1. Decide whose work this token is for

              A token reaches one owner: your own account, or one organisation. It can never see the other, whatever permissions you give it. So a person whose work lives in an organisation needs at least two tokens: one for the organisation, and one for their own account, which is where the board repository lives.

              Keep the board repository on a token owned by your own account. An organisation's owners can read its repositories, and these notes are meant for you alone.

              An organisation's owner may have to approve the token before it works. Until they do, the board sees nothing through it and says so.

            3. Copy the token

              GitHub shows the token once, on the screen that creates it, and never again. Copy it before you leave that page. If you lose it, you cannot read it back anywhere: you have to make another one.

            4. Paste it here

              GitHub does not say which owner a token belongs to, so the board cannot name it for you. Leave this empty and it suggests a name from wherever the token finds work. You can rename it in Settings at any time.
