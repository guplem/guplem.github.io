# My study tutor (example folder)

This folder is an AI agent that is already set up. It is the "Student" example from the guide:
https://triunitystudios.com/blog/your-first-agent/

What is inside:
- AGENTS.md: the instructions of the agent. CLAUDE.md only points to that file.
- data/: the memory (subjects, progress, assignments and notes).
- .agents/skills/ and .claude/skills/: the "practice-exam" recipe (the same in both).
- scripts/what-to-review.py: tells you which topics to review. It needs Python 3.
- exports/: a sample result, a one-page summary.

The data is only an example (an invented student). Delete it and add your own.

How to open it (first move the folder where you want it):
- Claude: open the desktop app, go to the Code tab and choose this folder.
- ChatGPT: open the app, switch to Codex mode, click "Add new project" and choose this folder.
- Antigravity: click the new project icon, then "Add Folder", choose this folder and click "Create".
- Goose: open Goose and choose this folder in the folder picker at the bottom bar. Before that, go to "Settings > Chat > Default Mode" and choose a mode that asks first, such as "Manual", so it asks you before it changes files.

To try it, type: "What should I review today?"
