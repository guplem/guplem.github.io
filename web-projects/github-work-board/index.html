Work board

Your GitHub issues, with notes only you can see.

Connect it, once

This page has no server. It talks to GitHub straight from your browser with a token you make yourself, and it keeps your notes in a private repository that you own.

  1. Make a private repository for your notes

    Call it work-board-data and set the visibility to Private.

    Open the new-repository page

  2. Make a fine-grained token

    Give it access to the repositories you work in and the notes repository, then grant exactly these:

    • Metadata → Read-only (GitHub requires it)
    • Issues → Read and write (the board reads your issues)
    • Contents → Read and write (your notes file)

    Set an expiry date. 90 days is a good default.

    Open the token page

  3. Paste it here

    The token stays in this browser and is sent only to GitHub. Anything else with access to this browser can read it, so keep it scoped to the repositories you need and give it an expiry date.
