# Weekly summary

1. Read data/log.csv and keep only the last 7 days.
2. If scripts/summary.py exists, run it to get the totals. If not, add them up yourself, carefully.
3. Compare with data/goal.md: am I on track?
4. Write the summary in exports/summary-DATE.md: totals, what went well and one single thing to improve.
5. Tell me the summary in three sentences.
