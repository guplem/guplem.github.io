This is the whole token

A token is a password. Whoever holds this one can do everything you granted it, on every repository you listed, until the day it expires. GitHub shows a token once and never again, so this copy is the only one left.

  • Keep it where you keep passwords. Never put it in a chat, an issue, or a screenshot.
  • Every app on this computer can read your clipboard, and Windows keeps a history of it.
  • If it does get out, delete it at your tokens and the board will say which one stopped working.

                1. Decide whose work this token is for

                  A token reaches one owner: your own account, or one organisation. It can never see the other, whatever permissions you give it. So a person whose work lives in an organisation and in their own account needs one token for each.

                2. Fill in GitHub's form

                  GitHub's form asks you four things. Here is the answer to each one.

                  An organisation's owner may have to approve the token before it works. Until they do, the board sees nothing through it and says so.

                3. Copy the token

                  GitHub shows the token once, on the screen that creates it, and never again. Copy it before you leave that page. If you lose it, you cannot read it back anywhere: you have to make another one.

                4. Paste it here

                  GitHub does not say which owner a token belongs to, so the board cannot name it for you. Leave this empty and it suggests a name from wherever the token finds work. You can rename it in Settings at any time.
