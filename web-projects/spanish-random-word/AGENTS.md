# spanish-random-word

"Palabra al azar": a random everyday Spanish word from Spain, with its definition hidden behind one button. The UI is in Spanish only. See `README.md` for features and ADR 0001 for the data decision.

## Module map

| File | Role |
|---|---|
| `wikitext.js` | Pure. Reads Wiktionary wikitext: the Spanish section, each part of speech, each numbered sense with its `{{ámbito}}` and `{{uso}}` labels. Holds every filter rule. |
| `pick.js` | Pure. Picks a word, reads and writes `?palabra=`, builds the API and dictionary URLs. |
| `words.js` | Generated by `tools/buildWordList.js`. Never edit it by hand. |
| `tools/buildWordList.js` | Offline build. Streams the Wiktionary dump and keeps the frequent words that `isEligibleWord` accepts. The page never loads it. |
| `app.js` | DOM glue only. Writes text with `textContent`. |
| `i18n.js`, `deployStamp.js` | The deploy line. `i18n.js` keeps the `{ en, es }` shape only because the copied `deployStamp.test.js` reads it. |

## Rules

- **Keep one set of rules.** The build script and the page both call `wikitext.js`. Put a new filter rule there, with a test, and never in `app.js` or in the build script alone.
- **Run the build script after a rule change that affects which words are eligible.** The page picks up a change to the shown senses at once, but `words.js` changes only when the script runs again. Commit the new `words.js` with the rule.
- **Keep `words.js` small.** It is the whole download. Do not add definitions to it (ADR 0001).
- **Keep the pinned words in `pick.test.js` true.** They guard the filter: "ordenador" and "coger" stay in, "computadora", "platicar", "guagua" and "empero" stay out.

## Gotchas

- **Send a `User-Agent` header from a script.** The Wikimedia API rate-limits a request without one, and it answers with plain text, not JSON. A browser sends one by itself.
- **Do not read the dump through the API.** One request per word hits the rate limit fast. The build reads the XML dump (about 90 MB compressed) instead.
- **A page can be a lemma and a form at once.** "casa" is a noun and a form of "casar". Only a plural or feminine form header (`Forma sustantiva`, `Forma adjetiva`) removes a word; a verb form removes it only when the verb is more frequent (`isFormOfCommonerVerb`).
- **Some senses are only a template.** `{{gentilicio|...}}` and similar templates clean to no text. `wikitext.js` drops a sense with no letters left.
