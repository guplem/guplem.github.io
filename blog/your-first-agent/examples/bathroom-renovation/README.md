# Bathroom renovation: example agent

This folder is a ready-made AI agent. It is the "Home renovation" example from the guide.
It works as a project manager: it keeps the steps, the contacts and the budget of a bathroom.

The files in the data/ folder are examples. The names and the phone numbers are invented. Delete them and put in your own.

## How to open it
- Claude Code: open the Claude desktop app, go to the Code tab and choose this folder.
- ChatGPT: open the ChatGPT app, choose Codex mode in the mode selector, click "Add new project" and choose this folder.
- Antigravity: click the new project icon, then "Add Folder" and choose this folder.
- Goose: choose this folder in the folder selector in the bar at the bottom. Before that, go to "Settings > Chat > Default Mode" and choose a mode that asks first (for example "Manual"), so that it asks you before it changes files.

Then write: "Who are you and what can you do?".
The money script needs Python 3. If you do not have it, the agent will do the sums itself.
