# Secret Santa (Amic invisible)

Draw Secret Santa names with exclusions and share one link. Each person picks their own name and opens a present that shows only who they give to.

## Features

- A shared link opens a page with nothing but the names, in large type. Pick yours, confirm, and open the present. It is simple enough for anyone.
- The organiser's editor hides behind a small link at the bottom. It starts with the names of the link you came from, and "Start over" clears it.
- Add people one by one or paste a whole list.
- Tap who each person must not give to. Exclusions can work both ways, for couples.
- Add an optional note of up to 100 characters (budget, date, place, a joke). It shows after the name is revealed.
- "Make the link" opens a share screen: copy the link in one tap, or copy a ready-made message in Catalan, Spanish or English, then send it on WhatsApp or another app.
- One share link holds the whole event and a fresh seed for every draw. Every phone works out the same result, and the result itself is never in the link.
- A warning names the person before anything is shown, so nobody spoils the surprise by mistake.
- This device remembers who you are for each draw. Open the link again and you go straight to your own present. A small link at the bottom lets you change who you are if you picked the wrong name.
- An animated present, confetti and snow. All motion stops when the system asks for reduced motion.
- Catalan, Spanish and English, chosen from the system language.

## How to Run

Open `index.html` through any HTTP server, for example `python -m http.server` from the repository root.
